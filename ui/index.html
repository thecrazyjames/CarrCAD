LINEWORK MODIFIERS

Trim / extend: select one or more cutting boundary LINEs, start the command, then click target LINEs. Trim removes the clicked interval (and splits a LINE if needed); extend picks the nearest boundary along the clicked endpoint. Press Enter or Esc to finish.

Fillet / chamfer: select exactly two intersecting LINEs, start the command, and click the desired corner. Geometry that cannot be represented exactly is rejected.

TEXT STYLES

CIVIL LABEL STYLES
